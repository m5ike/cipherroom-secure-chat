# Phone bridge

Lends a phone number (10 minutes by default) with a 5-digit code: whoever calls it and types the code and # is connected with the member — audio in their browser, or speech to text and their written replies spoken back.

Chat: `/phone-bridge` — a form; sending it runs the `form` function.

Built as a flow: open it in Functions › Builder (flow.m5flow.json); index.js is what it compiles to.

Needs the Telephony & SIP module (a provider configured, and your rights: Modules & groups). Its model starts switched off: it costs money.
