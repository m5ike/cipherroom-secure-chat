# Parts — nativní části obrazovek (vlna 2)

Port `A/ui/parts/*`, `A/ui/bubble/*`, `A/ui/look/*`, `A/ui/media/*` (přehrávače, náhledy) a UI `A/fn/*`
(`A/` = `android/app/src/main/java/cz/m5cet/app/`) ve SwiftUI — části, které design vkládá do svých slotů
(seznam místností, zprávy, skladač, hovor, profil, NFC, nastavení…). Logika bez UI je v `M5Kit`, systémové služby
v `Platform/*`.
