Telephony & SIP console


      

      
Voice + SMS via Twilio / Telnyx / Vonage. Keys come from server env (ENABLE_TELEPHONY=1). The audio/media path needs an external SIP↔WebRTC gateway — this console manages providers, webhooks, trunk config + DID routing.

      


      
Default providers

      
Which provider handles SMS and which handles voice. Order: request → this choice (persisted) → SMS_PROVIDER / VOICE_PROVIDER in .env → first configured.

      

        
        
        
        
        
      

      


      
Webhooks (/wh/{provider}/{type})

      
Served by the main app. Set PUBLIC_BASE_URL so the URLs are absolute, then "Install" pushes them into the provider. Signatures are verified when TWILIO_AUTH_TOKEN / TELNYX_PUBLIC_KEY / VONAGE_SIGNATURE_SECRET are set.
